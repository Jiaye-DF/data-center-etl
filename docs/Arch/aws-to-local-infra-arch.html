架構規劃 · 端到端資料中樞

Enterprise Data Hub — 地端 → AWS 資料中樞架構

以原始系統方向為骨幹：地端 ERP/BPM/HRM → Migration → Raw-Data-Replication → Glue Catalog + 自架 Taskiq ETL → ETL-Hub → Data Hub → 業務系統。整合 Phase 1 實測成果，補齊整體 AWS 設施，並納入 Phase 2–4 未來規劃。

範圍　Phase 1 基礎建設（Full Load）· Phase 2 ETL（VPC Endpoints · Crawler + Data Catalog / Lake Formation · ETL 執行改自架 Taskiq + Redis） 區域　AWS 東京 ap-northeast-1（AZ 1a / 1c）
總覽

I目標

規劃地端資料庫同步至雲端機器架構，含資料複製 / 移轉 / Hub / Center。

系統架構流程

  1. 地端資料透過 Migration（DMS，Full Load + CDC）：資料寫入 RDS（Raw-Data-Replication），異動紀錄推送 Kinesis Data Streams，再由 Lambda 消費寫入同座 RDS 的 erp_cdc_event_logs DB
  2. AWS Glue Crawler / Data Catalog 建 Metadata；ETL 轉換改自架 Taskiq + Redis（Coolify on EC2）寫回 RDS（ETL-Hub）
  3. Data Hub 讀取 ETL-Hub 供各業務系統應用
  4. AWS EC2 設置（Data Hub / Center 運算）

原始建置步驟

  1. ERP / BPM / HRM Data（Oracle / SQL Server）
  2. AWS VPC（企業內網 10.0.0.0/16）
  3. VPC Subnet（東京 1a / 1c）
  4. Route Table（加 10.200.0.0 / 10.240.0.0 網段）
  5. Security Group
  6. RDS
  7. DMS
Phase 1 實測先以 Oracle → Raw-Data-Replication（PostgreSQL RDS）Full Load 驗證；SQL Server 與 CDC（→ Kinesis → Lambda → erp_cdc_event_logs） 在後續階段納入。
📖 本頁名詞
DMS
AWS 資料庫遷移服務（Oracle / SQL Server → RDS）。
RDS
AWS 託管關聯式資料庫（本架構皆 PostgreSQL）。
Raw-Data-Replication
DMS 直寫落地的原始複製 DB，保留來源樣貌、不轉換。
AWS Glue
Crawler / Data Catalog 建立來源 Metadata（本案 ETL 轉換改自架，不用 Glue Job）。
自架 Taskiq + Redis
容器化 ETL：Worker 直連 RDS 完成 Raw → ETL-Hub 轉換，Coolify 部署於 EC2。
ETL-Hub
經 ETL（自架 Taskiq）轉換後的 RDS，供業務 / 分析使用。
Data Hub / Center
讀取 ETL-Hub 對外供應資料的應用層（EC2）。
EC2
虛擬主機，執行 Data Hub / Center 運算。

Phase 2 · ETL / Glue

VIGlue 前置：VPC Endpoint 問題與解法

建置步驟（實作除錯紀錄）

實際建 Glue Connection 的過程是「逐一補齊缺的 Endpoint」——每補一個就往前推進一個錯誤，直到全部到位。

Step動作結果 / 錯誤
1建 Glue Connection（PostgreSQL；選與 RDS 同 VPC、Private Subnet-A/C；初期先用 RDS SG）建立連線設定
2測試連線❌ Failed to assume customer's role / access to STS — 私網無法連 sts
3建 STS Interface Endpoint（Private DNS on、Subnet-A/C、SG-VPCE-AWS-Services）可 AssumeRole，往前一步
4再測❌ Unable to connect to Secrets Manager — Glue 憑證存在 Secrets Manager
5建 Secrets Manager Interface Endpoint（設定同 STS）可讀連線憑證
6建 CloudWatch Logs Interface Endpoint（Glue Job 要寫執行日誌）可寫 Job log
7建 S3 Gateway Endpoint（不是 Interface！改 Route Table RT-ERP-Hub-Test-DB，AWS 自動加 Prefix List pl-xxxx）可存取 S3
8建共用 SG-VPCE-AWS-Services（Inbound 443 ← Glue SG；Outbound All）Endpoint 流量放行
9核對 VPC Endpoint 總表（見下）4 個到位

XIII名詞解說（一）網路 · Glue 前置 · 遷移

名詞完整索引上半：網路 / 連線、VPC Endpoint 與 Glue 前置、遷移 / 資料庫。ETL 執行、分析 / AI、安全維運與專案自訂命名見〈XIV〉；各頁底部另有「📖 本頁名詞」就地速查。

網路 / 連線

名詞全稱 / 類型說明
VPCVirtual Private CloudAWS 上的私有虛擬網路,本架構用 10.0.0.0/16 隔離所有資源。
CIDR網段表示法如 10.0.32.0/24,`/24` 代表可用 256 個 IP;用來劃分子網範圍。
AZAvailability Zone同區域內物理隔離的機房(本架構用東京 1a / 1c),跨 AZ 提升可用性。
Subnet子網VPC 內的網段切分:Public(對外)、Private(DMS / Glue)、DB(RDS)。
IGWInternet GatewayVPC 對公網的進出入口,只有 Public Subnet 經它通網際網路。
NAT Gateway網路位址轉換閘道讓私有子網「只出不進」連外;本架構 Phase 2 刻意改用 VPC Endpoint 而不開 NAT。
VGWVirtual Private GatewayVPC 端的 VPN 落地閘道,與地端對接 Site-to-Site VPN。
Site-to-Site VPN站對站 VPN地端機房 ↔ AWS 之間的 IPsec 加密通道。
Route Table路由表決定封包往哪走(Local / VGW / NAT);本架構只新增、不移除既有路由。
Security GroupSG / 安全群組執行個體層級的虛擬防火牆,以「方向 + Port + 來源」控管,可互相引用。
NACLNetwork ACL子網層級的無狀態防火牆,排查連線問題時的檢查項之一。
VPC EndpointVPC 端點讓私網不經公網即可存取 S3 / STS 等 AWS 服務(走 AWS Backbone)。

VPC Endpoint / Glue 前置（Phase 2）

名詞全稱 / 類型說明
STSSecurity Token Service發放臨時安全憑證的服務;AssumeRole 靠它換取角色權限。
AssumeRole取得角色臨時憑證服務(如 Glue)啟動時向 STS 換取 IAM Role 的臨時權限。
Interface EndpointVPC 端點(ENI 型)在子網建 ENI、吃 SG、走 Private DNS,存取 STS / Secrets / Logs 等。
Gateway EndpointVPC 端點(路由型)S3 專用,改 Route Table、不建 ENI / 不吃 SG。
ENIElastic Network Interface彈性網卡;Interface Endpoint 在子網內的網路介面。
Private DNS私有 DNS 解析讓 AWS 服務網域自動解析到 Endpoint 的私有 IP。
Glue ConnectionGlue 連線設定Glue 連 RDS / 資料源的連線,含 VPC / Subnet / SG。
Glue Crawler爬蟲掃描資料源結構,寫入 Data Catalog。
Lake Formation資料湖權限治理在 IAM 之上對 Glue Catalog 的 Database / Table / Column 做細粒度授權;Crawler 寫 Metadata 需先過它。
IAMAllowedPrincipalsLF 相容群組資源持有它時退回 IAM-only 授權;被移除即翻轉成 Lake Formation 強制授權。
Data Lake Administrator資料湖管理員Lake Formation 最高權限者,可對各資源授權 / 撤銷。
Hybrid Access Mode混合授權模式IAM 與 Lake Formation 授權並存的過渡模式;本案未使用。
ECRElastic Container Registry容器映像倉庫;跑容器化任務時需要(選用 Endpoint)。
SSMSystems Manager參數 / 遠端管理;選用 Endpoint。

遷移 / 資料庫

名詞全稱 / 類型說明
DMSDatabase Migration ServiceAWS 資料庫遷移服務,負責把 Oracle/SQL Server 資料搬到 RDS。
Replication InstanceDMS 複寫主機實際執行遷移的運算資源,本架構用 dms.t3.medium。
Full Load全量載入一次性把來源既有資料整批複製到目標(Phase 1 範圍)。
CDCChange Data Capture變更資料擷取,持續同步來源「之後的增刪改」(Phase 2 才導入);本架構 CDC 的目標端點指向 Kinesis 而非直寫 RDS。
Kinesis Data Streams即時串流服務承接 DMS CDC 推送的異動 event log(JSON,含操作別與 before / after image),保留期內可重放。
ShardKinesis 分片Kinesis 的吞吐單位;partition key 決定事件落在哪一片,同片內保證順序。
Event Source MappingLambda 事件來源對應Lambda 輪詢 Kinesis 並批次觸發的設定(本架構以此取代 EventBridge 觸發)。
Lambda(CDC Consumer)無伺服器函式消費 Kinesis 異動事件、寫入 erp_cdc_event_logs DB;與 ETL 層的自架 Taskiq 分屬不同層(前者處理 CDC 事件,後者做 Raw → ETL-Hub 轉換)。
erp_cdc_event_logs異動事件 DB(專案自訂)與 Raw-Data-Replication 同一座 RDS 實例的另一個 DB;存放 Lambda 由 Kinesis 消費而來的來源異動事件紀錄。
Endpoint來源 / 目標端點DMS 連線設定(Host / Port / 帳密);Source = Oracle,Target = PostgreSQL(Full Load)/ Kinesis Stream(CDC)。
Table Mapping表對應規則用白名單指定只同步哪些 Schema / Table(如 DS.*、M2201.*)。
LOBLarge Object大型欄位(BLOB/CLOB);本架構用 Limited LOB 32KB 限制單筆上限。
RDSRelational Database ServiceAWS 託管關聯式資料庫;本架構兩座皆 PostgreSQL。
DB Subnet Group資料庫子網群組RDS 可部署的子網集合,須含 ≥2 AZ。
Multi-AZ多可用區部署RDS 在另一 AZ 維持待命副本,故障自動切換(正式環境建議)。
gp3SSD 儲存類型RDS 通用型 SSD,支援線上擴充容量(只增不減)。

XIV名詞解說（二）ETL · 分析 · 安全 · 命名

名詞完整索引下半：轉換 / 編排 / 運算、分析 / AI、安全 / 維運、專案自訂命名。上半（網路 · Glue 前置 · 遷移）見〈XIII〉。

轉換 / 編排 / 運算

名詞全稱 / 類型說明
AWS Glue無伺服器 ETLCrawler / Data Catalog 建立來源 Metadata(本案 ETL 轉換改自架,不用 Glue Job)。
ETLExtract-Transform-Load擷取 → 轉換 → 載入,資料整理的標準流程。
Data Catalog資料目錄Glue 維護的表結構/中繼資料庫,供 Athena/Glue 查詢用。
TaskiqPython 分散式任務佇列自架 ETL 的排程(scheduler)與執行(worker);取代 Glue Job + EventBridge / Lambda。
Redis記憶體資料存儲Taskiq 的 broker(訊息佇列),排程派工經此傳遞。
Docker Compose容器編排一鍵起跑自架 ETL 各服務(worker / scheduler / redis 等)。
Coolify自架 PaaS / CD把容器化 ETL 部署於 EC2,管理發布。
EC2Elastic Compute Cloud虛擬主機;本架構執行 Data Hub / Center 並承載自架 ETL 容器(Taskiq / Scheduler / Redis)。

分析 / AI

名詞全稱 / 類型說明
S3 Data Lake物件儲存資料湖集中存放各類原始 / 加工資料的低成本儲存層(Phase 3)。
Athena互動式查詢直接對 S3 用 SQL 查詢,免建資料庫(Phase 3)。
Redshift資料倉儲大規模分析 / BI 用的欄式資料倉儲(Phase 3)。
RAGRetrieval-Augmented Generation檢索增強生成:先檢索知識庫再讓 LLM 生成,降低幻覺(Phase 4)。
MCPModel Context Protocol讓 AI Agent 標準化存取外部工具 / 資料來源的協定(Phase 4)。
Knowledge Base / Agent Platform知識庫 / 代理平台AI 應用層:沉澱企業知識並由 Agent 對外提供服務(Phase 4)。

安全 / 維運

名詞全稱 / 類型說明
IAM Role身分與存取角色授予服務(DMS/Glue/EC2)最小必要權限的角色。
Secrets Manager機密管理集中保管 DB 帳密 / 金鑰,避免寫死在程式或設定。
KMSKey Management Service管理靜態加密金鑰(RDS / S3 加密)。
CloudWatch監控服務收集 Logs / Metrics 並設定 Alarms 告警。
CloudTrailAPI 稽核記錄誰在何時對哪個資源做了什麼 API 操作。

專案自訂命名

名詞說明
Raw-Data-Replication地端資料經 DMS 直寫落地的「原始複製」DB,保留來源樣貌、不做轉換。
erp_cdc_event_logs與 Raw-Data-Replication 同一座 RDS 實例的另一個 DB;存放 Lambda 由 Kinesis 消費而來的來源異動事件紀錄。
ETL-Hub經 ETL(自架 Taskiq)清洗轉換後的 RDS,供業務系統與分析使用。
Data Hub / Center讀取 ETL-Hub 對外供應資料的應用層(EC2),企業資料中樞。
