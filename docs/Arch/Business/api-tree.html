api-clients(8)— 建立 / 更新 / 註銷 / 密鑰清單 / 明文檢視 / 輪替 / 汰換(單一密鑰制)
/api/client/v1.0模組① 2 端點
POST/token— client_id + secret → 15 分鐘 JWT;錯誤一律 401 invalid_client;限流 429
POST/refresh_token— 過期 token + 憑證語意刷新(無 refresh token 設計)

模組② 組織權限管理 規劃 · v1.6.1/api/v1 · 全 admin

階層:系統別 → 作業 → 設定檔 → Role → API Client;特例權限直綁可設效期;加法模型無 deny;表 / 欄位一律語意層英文名(僅 confirmed 可選)。
/services系統別(erp / crm / hrm / bpm / zpos…)
GET/services— 分頁清單
POST/services— 建立(code 唯一)
PATCH/services/{uid}— 更新(code 禁改)
DELETE/services/{uid}— 軟刪(仍有作業 → 409)
/operations作業:歸屬系統別,定義表 × 欄位「範圍」(上限,不決定最終回傳)
GET/operations?service_uid=— 分頁清單
POST/operations— 建立(name 系統別內唯一)
PATCH/operations/{uid}— 更新(禁改歸屬)
DELETE/operations/{uid}— 軟刪(被設定檔引用 → 409)
GET/operations/{uid}/items— 表 × 欄位範圍(* = 全欄位)
PUT/operations/{uid}/items— 整批置換範圍(非 confirmed 欄位 → 422)
/permission-profiles角色權限設定檔:Profile → Operation → Table → Column → Read/Edit
GET/permission-profiles— 分頁清單
POST/permission-profiles— 建立(name 唯一)
PATCH/permission-profiles/{uid}— 更新
DELETE/permission-profiles/{uid}— 軟刪(被 Role 綁 → 409)
PUT/permission-profiles/{uid}/operations— 整批置換勾選作業
PUT/permission-profiles/{uid}/operations/{op_uid}/items— 該作業下授權矩陣整批置換(超出範圍 → 422)
/client-rolesRole:必綁 1 個設定檔(禁空);命名避開既有 /roles
GET/client-roles— 分頁清單
POST/client-roles— 建立(未帶設定檔 → 422)
PATCH/client-roles/{uid}— 更新 / 改綁設定檔
DELETE/client-roles/{uid}— 軟刪(被 Client 綁 → 409)
/exception-sets特例權限組:結構同設定檔,直綁 Client 可設效期
GET/exception-sets— 分頁清單
POST/exception-sets— 建立
PATCH/exception-sets/{uid}— 更新
DELETE/exception-sets/{uid}— 軟刪(仍被綁定未過期 → 409)
PUT/exception-sets/{uid}/operations— 整批置換臨時作業
PUT/exception-sets/{uid}/operations/{op_uid}/items— 臨時授權矩陣整批置換
/api-clients/{uid}/…Client 指派與預覽(擴充既有資源;只綁 0..1 Role + 特例 0..N)
PUT/api-clients/{uid}/role— 指派 / 改指派 Role(冪等置換)
DELETE/api-clients/{uid}/role— 解除 Role
GET/api-clients/{uid}/exception-sets— 特例綁定清單(含效期 / 是否過期)
POST/api-clients/{uid}/exception-sets— 綁定特例 {exception_set_uid, expires_at?}
DELETE/api-clients/{uid}/exception-sets/{binding_uid}— 解除單筆綁定
GET/api-clients/{uid}/effective-permissions— 預覽最終可見欄位:Role ∪ 特例(濾過期)∩ 作業範圍;default-closed

模組③ 權限引擎 規劃判斷面多為內部依賴,僅少量管理端點

每筆資料請求三段式判斷:作業級(未授權 403)→ 展開範圍 → 逐表交集(授權 ∩ 範圍,空 = 200 空 data);展開結果 Redis TTL 快取,模組② 異動即失效;JWT 不塞權限,停權即時生效。
/authz引擎管理面(admin)
GET/authz/clients/{uid}/effective— 引擎視角展開結果(與模組② 預覽共用實作;附快取狀態,除錯用)
POST/authz/cache/invalidate— 手動失效權限快取 {client_uid?}(不帶 = 全體;保險絲)

模組④ 資料供應 API 規劃/api/client/v1.0 · Bearer JWT · 統一封套 · data 依表分組

SQL 層欄位投影(只 SELECT 可見欄位)查 ETL-Hub 語意 View;限流沿用 rate_limit:client:<client_id>。
探索串接方自查可用範圍
GET/services— 我有權限的系統別清單
GET/{service}/operations— 該系統別下我可用的作業
GET/{service}/operations/{operation}— 作業中繼:各表可見欄位與動作
查詢(read)
GET/{service}/operations/{operation}/data— 主查詢;參數:fields(未帶 = 授權全集)/ table / page / page_size / sort / filter[field] / updated_since;未授權欄位直接忽略
寫入(edit = 新增 / 更新 / 刪除)需 edit 授權;落地 ETL-Hub,寫回 ERP 另案
POST/{service}/operations/{operation}/tables/{table}/rows— 新增一列(含未授權欄位 → 403,寫入不忽略)
PATCH/{service}/operations/{operation}/tables/{table}/rows/{row_uid}— 部分更新(僅 edit 授權欄位)
DELETE/{service}/operations/{operation}/tables/{table}/rows/{row_uid}— 一律軟刪除,禁物理刪除

模組⑤ 稽核 規劃對外請求留痕,與後台 audit_logs 分表

/client-request-logsadmin 查詢面;寫入由模組④ middleware 非同步落 api_client_request_logs
GET/client-request-logs— 分頁;過濾 client / service / operation / 狀態碼 / 起訖時間
GET/client-request-logs/summary— 聚合概覽(請求數 / 錯誤率 / 429 / Top Client)
GET/api-clients/{uid}/request-logs— 單一 Client 視角(設定頁內嵌)
