# Business 商業語言版

`docs/Arch/` 技術架構文件的**商業語言簡報版**：不逐段翻譯技術內容，而是重新編排成給管理層看的簡報 — 一頁一個概念、大字大圖、全程比喻、零技術術語，完全非技術背景也能看懂。

- 檔名以 `-brief` 結尾，對應 `docs/Arch/` 的原始技術文件（如 `datahub-api-gateway-brief.html` ↔ `datahub-api-gateway-arch.html`）
- 形式為整頁滾動的 HTML 簡報（一路往下捲、不需翻頁，可列印成 PDF），聚焦「解決什麼問題、帶來什麼效益」
